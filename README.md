# Flicker

[Pobierz Flicker 4.0 — wydanie Windows](https://github.com/F0r3mn14k/Flicker/releases/tag/v4.0.0)

- **v1.0/** — zachowana wersja 1.0: `Flicker-1.0.exe`, archiwum źródeł, rozpakowane źródła w `source/` i suma SHA256.
- **v2.0/** — zachowana wersja 2.0: `Flicker-2.0.exe`, kod, zasoby, instrukcja i skrypty budowania.

Budowanie: `powershell -ExecutionPolicy Bypass -File .\v4.0\build.ps1`

Testy i podglądy: `powershell -ExecutionPolicy Bypass -File .\v4.0\verify.ps1`

Wersja 1.0 pozostaje też zachowana pod lokalnym tagiem Git `v1.0`. Pliki wykonywalne i archiwa są lokalne; Git przechowuje kod źródłowy. Ustawienia aplikacji pozostają w LocalAppData i nie są przenoszone z folderami projektu.

- **v2.5/** — zachowana wersja z poprawioną obsługą znaków klawiatury: `Flicker-2.5.exe`, kod i testy. Propozycje rozbudowy: `v2.5/VERSION-2.5.md`.

- **v3.0/** — zachowana wersja: `Flicker-3.0.exe`, edytor sekwencji i klasyczny harmonogram.

- **v4.0/** — aktualna wersja: `Flicker-4.0.exe`, profile z importem i eksportem, sekwencje i harmonogram.
